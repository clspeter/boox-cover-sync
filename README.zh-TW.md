# BOOX Cover Sync

**讓正在閱讀的書封，成為 BOOX 的休眠與關機畫面。**

不需要 Root · 裝置本機處理 · 可選用背景同步

將 EPUB 封面設為 BOOX 螢幕保護畫面：開啟 App，就會依 NeoReader 最近閱讀紀錄同步一次；也能自行選書。想自動換封面時，可以開啟背景同步。

> [!NOTE]
> 已在 **BOOX Page／BOOX 4.2** 測試；其他機型與韌體尚未確認。目前 App 介面為**繁體中文**。

## 選擇同步方式

| 方式 | 怎麼使用 | 無障礙服務 |
| --- | --- | --- |
| **開 App 同步一次** | 在 NeoReader 閱讀後，開啟 BOOX Cover Sync。 | 不需要 |
| **自己選 EPUB** | 選擇書籍並套用封面。 | 不需要 |
| **背景自動同步** | 啟用自動同步，並允許背景執行。 | 需要 |

## 快速開始

1. 開啟[最新版本](https://github.com/clspeter/boox-cover-sync/releases/latest)，下載附件中的 `.apk` 並在 BOOX 上安裝；若系統要求，允許該來源安裝應用程式。
2. 開啟 **BOOX Cover Sync**。若無法讀取書籍或套用封面，點 **「開啟公共儲存空間設定」**，允許管理所有檔案。
3. 在 **NeoReader** 開啟 EPUB，再從桌面開啟 **BOOX Cover Sync**，App 會自動同步一次。
4. 等畫面顯示 **「同步完成」**，再讓裝置休眠，確認封面。

App 已開啟時，按 **「同步最新閱讀封面」** 就能重試。這個模式不需要電腦，也不需要無障礙服務。

> [!TIP]
> **還是前一本書？** BOOX 閱讀紀錄可能延遲，請等約 **20 秒**再試。若仍不正確，可以依下方步驟直接選擇 EPUB。

## 自己選擇封面書籍

1. 點 **「選擇 EPUB」**。
2. 選取書籍，確認封面預覽。
3. 開啟 **「同步休眠畫面」**、**「同步關機畫面」**，或同時開啟兩者。
4. 點 **「立即重新同步」**。

兩個畫面開關預設都開啟，重新開啟 App 後可能恢復預設值；同步前請再次確認。設定關機封面**不會立即關機**。

## 選用功能：背景自動同步

1. 在 BOOX「應用」頁長按 App 圖示，若看到 **「解凍」**就點選它。
2. 開啟 **「優化」→「其它」→「允許後台持續運行」**，選擇 **「持續運行」**並確認。
3. 到系統 **「無障礙」**設定，啟用 **BOOX Cover Sync**。
4. 回到 App，開啟 **「啟用自動同步」**。
5. 在 NeoReader 換一本 EPUB，**停留約 10 秒**等待同步後再讓裝置休眠，確認封面。

選單名稱會因機型、韌體與系統語言不同而有差異；「持續運行」也可能顯示為「無限制」或 Unlimited。背景同步會同時更新**休眠與關機封面**，不受手動同步的畫面開關控制。

> [!IMPORTANT]
> **只解除凍結可能還不夠。** 實測 BOOX 另有 **5 分鐘背景執行上限**，時間到了可能停止更新。請改為「持續運行」，並在切換 E InkWise 設定檔或重新安裝 App 後再次確認。
>
> 只喚醒螢幕，不一定能恢復被系統停止的 App。此時可手動開啟 BOOX Cover Sync，再同步一次。
>
> 開書後通常約 5 秒內完成同步。**開書後立刻休眠**時，休眠會取消尚未完成的同步，這次仍顯示上一本書；喚醒後 App 會補同步，下次休眠才換成新封面。

想優先省電，請關閉 **「啟用自動同步」**，需要換封面時才開 App。「持續運行」不會讓螢幕一直亮著，但背景處理仍可能增加耗電；目前沒有實際耗電數據。

## 更新版本

已安裝正式版時，直接安裝新版官方 APK 即可保留設定。若顯示無法安裝，先確認 APK 來源與簽章相容性，再決定是否卸載。

> [!WARNING]
> 先前的 **debug 測試版使用不同簽章**，無法直接覆蓋安裝正式版。切換時需先卸載測試版，這會移除 App 設定與授權；安裝後請重新設定權限及 BOOX 背景選項。

## 已知限制

| 項目 | 使用時需要知道的事 |
| --- | --- |
| **裝置相容性** | 僅在 BOOX Page／BOOX 4.2 測試。封面尺寸針對 Page 設計，其他裝置的顯示效果與行為尚未確認。 |
| **書籍格式** | 目前只支援 EPUB，且書籍內需有封面圖片宣告；不支援 PDF 封面擷取。DRM 保護或沒有讀取權限的書籍可能無法使用。 |
| **最近閱讀判定** | 依 BOOX 書庫紀錄的更新時間（`updatedAt`、`lastAccess` 取較新者）判斷正在讀的書，僅在 BOOX Page 的 NeoReader 實測。其他 App（例如雲端同步）若更新了另一本書的紀錄，可能誤判；直接選擇 EPUB 可避開這項判定。 |
| **背景穩定性** | BOOX 仍可能停止 App。目前只通過短時間背景測試，長時間運作與耗電尚未驗證；尚未實作無障礙快捷按鈕。 |
| **畫面設定與完成提示** | 手動同步的畫面開關不會跨 App 重啟保存；背景同步固定更新兩種畫面。「同步完成」代表已送出請求，仍需確認實際休眠畫面。 |
| **儲存空間** | 每本書產生的封面圖片可能持續累積，目前沒有自動清理功能。 |
| **介面語言** | App 目前為繁體中文介面；切換 README 語言不會改變 App 語言。 |

## 常見問題

| 遇到的情況 | 可以怎麼做 |
| --- | --- |
| 封面還是之前的書 | 開書後等約 10 秒再休眠；仍不對就按 **「同步最新閱讀封面」**，或用 **「選擇 EPUB」**。 |
| 過幾分鐘就不更新 | 確認已解凍，並將背景執行時間改成 **「持續運行」**。 |
| 無障礙開著卻沒反應 | 將本 App 的無障礙服務關閉再開啟，或直接開 App 手動同步。 |
| 找不到書籍或讀取失敗 | 確認書籍是 EPUB、檔案仍在裝置上，並檢查儲存空間授權。 |
| 顯示完成，但休眠圖沒換 | 檢查預覽與 **「同步休眠畫面」**開關，再同步一次；仍失敗時確認儲存空間授權。 |

部分權限提示保留作診斷用途，不代表手動同步一定無法使用。可以先嘗試同步；需要進一步排查時，請看技術文件。

## 隱私

書籍解析與封面處理都在**裝置本機**完成。App 不要求網路存取權限，也不會上傳書籍。封面預覽與輸出圖片仍可能包含書名，分享截圖或檔案前請先確認內容。
